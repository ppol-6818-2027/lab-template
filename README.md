# PPOL 6818: your lab repository

This repository is yours alone, `lab-<your GitHub username>`, and holds every week's lab. Open it from the **Open RStudio** button on Canvas: one codespace holds this repository and, once pairs are formed, your pair's project repository beside it (switch between them in RStudio's **Projects** menu, top right).

- `week-01/`, `week-02/`, ...: each week's lab. The course adds the week's starter files before class; you do your work in that folder.
- `course/project`: the name of your pair's project repository. The course writes it; do not edit it.

A lab is done when you have committed your work in that week's folder and pushed it: in RStudio's **Git** pane, tick the files, click **Commit**, write a short message, then click **Push**.

## Week 1: your pitch

1. Write your slide in `week-01/pitch.md`, in your own words, at most 60 words: a title, the policy, where it varies, your question, and one line about you. Fill in your name and GitHub username at the top.
2. Optionally, ask the course agent (**Addins > Course agent**) to draw one figure from data with R code (`week-01/run.R`) into `week-01/pitch.png`. The agent formats and draws; it does not write or edit your words.
3. Commit `week-01/pitch.md` (and `week-01/pitch.png`) and push by the end of the lab: then the course combines every slide into the class deck.
